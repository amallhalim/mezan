# 🛠️ Technology Stack

This project is a modern web application built with the following core technologies:

## 🌐 Core Framework
- **[Next.js](https://nextjs.org/) (v16.2)**: Using the **App Router** for routing and server components.
- **[React](https://react.dev/) (v19)**: The foundational UI library.
- **[TypeScript](https://www.typescriptlang.org/)**: For static type checking and better developer experience.

## 🎨 Styling & UI
- **[Tailwind CSS](https://tailwindcss.com/)**: For utility-first responsive styling.
- **[Lucide React](https://lucide.dev/)**: For high-quality, lightweight icons.
- **Modern Aesthetics**: Custom glassmorphism, dark mode, and vibrant color palettes.

## 🧠 State Management
- **[Zustand](https://zustand-demo.pmnd.rs/)**: A small, fast, and scalable bearbones state-management solution used for tracking the "Meal Plate" and calorie calculations.

## 🧪 Testing Infrastructure
- **[Vitest](https://vitest.dev/)**: A blazing fast unit test framework powered by Vite.
- **[React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)**: For testing components as the user would see them.
- **[JSDOM](https://github.com/jsdom/jsdom)**: A pure-JavaScript implementation of the DOM for testing without a real browser.

## 📦 API & Data
- **Axios**: For handling HTTP requests.
- **Next.js API Routes**: Serving as the backend for food data and calculations.
